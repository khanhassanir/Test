# Mobile AI Coding Assistant (Android App) - Project Plan in Plain English

## 1. What This App Is and How It Works
- **Runs on Android Phones:** This app is designed specifically for Android smartphones.
- **No Outside Servers Needed:** Everything runs directly on your phone. You don't need a separate computer or cloud server to run the AI assistant engine.
- **Built-in Assistant Engine:** The app carries its own mini-engine (Node.js and the Antigravity assistant tool) bundled inside it. When you open the app, this engine quietly starts up in the background on your device.

## 2. Signing In
- **Google Login:** When you open the app for the first time, you simply sign in with the Google account that has your Antigravity subscription.
- **Uses Your Own Account Limits:** This makes sure any AI requests you make use your personal account permissions and daily allowances.

## 3. Connecting to Your Code
- **Easy GitHub Connection:** You don't need to know complicated Git commands or terminal tools.
- **Just Paste a Link:** Simply paste a link to your GitHub project. The app will look up your project files and let you pick what you want to work on.

## 4. Chatting and Working on Code
- **Direct Chat:** The app gives you a simple chat screen where you can talk to the coding assistant.
- **Instant Setup:** As soon as you link a project, the app automatically gives the assistant the information it needs to start helping you immediately.
- **Fast, Private Communication:** The chat screen talks directly to the engine running right inside your phone.

## 5. Easy-to-Understand Summaries of Changes
- **Simple, Clear Answers:** Instead of overwhelming you with confusing technical jargon, the assistant gives short, easy-to-read summaries.
- **Visual File Changes:** You can easily see which files were created, updated, or removed right on your phone screen.

## 6. How It Is Built (In Simple Terms)
- **App Interface:** Built with Flutter so it looks clean, smooth, and modern on your phone.
- **Phone-Based Engine:** An internal engine that runs on Android to execute the coding assistant.
- **Connections:** Simple links to GitHub to view your code, and an internal link between the chat screen and the assistant engine inside the app.
