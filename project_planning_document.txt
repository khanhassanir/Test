# Mobile AI Coding Agent - Project Plan

## 1. What This App Does
- **Runs on Your Phone:** An AI coding assistant made for Android phones and tablets.
- **No Outside Servers:** Everything runs directly on your device.
- **Ready to Go:** Comes with everything built inside, so you do not need to install extra tools.

## 2. Accounts & Login
- **Google Account:** Sign in to use your Antigravity AI plan and limits.
- **GitHub Account:** Sign in so the app can open your code and save changes back.

## 3. Opening Your Code
- **Pick a Project:** Paste a link to a GitHub repository or pick one from your account.
- **No Git Setup Needed:** The app downloads the project files for you without needing command-line tools.

## 4. Chatting & Editing
- **Talk to the AI:** Ask the AI to write, edit, or fix code in a simple chat window.
- **Works Automatically:** Starts setting up the project the moment you open it.

## 5. Seeing Changes & Sending to Git
- **Clear Previews:** See an easy list of all files created, changed, or deleted.
- **Send Changes to Git:** Tap one button to send your updates straight back to GitHub as a commit or new branch.

## 6. What Powers It
- **App Screen:** Built with Flutter for a smooth mobile experience.
- **Local Engine:** Built-in engine that runs directly inside the Android app.
- **GitHub Connection:** Direct connection to download your code and send your changes back.
